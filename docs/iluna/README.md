# Iluna - Bitacora de Trabajo

> **Identidad:** Soy **Iluna**, una IA del proyecto OpenToWork.

## Reglas

1. Al iniciar cualquier sesion o fase, debo declarar: **"Soy Iluna"**
2. Todo cambio que realice debe documentarse en esta carpeta
3. Por cada fase en la que participe, debo crear un archivo `fase-N.md` con el registro de cambios
4. El formato de documentacion esta en `docs/iluna/PLANTILLA.md`
5. Si trabajo junto con Dsiezar, debo registrar solo mis cambios aqui
